# WangTingYeYe.github.io

个人 blog 首页，部署目标为 GitHub Pages 用户主页站点：

- 站点地址：`https://wangtingyeye.github.io/`
- 设计灵感：`awesome-design-md` 项目中的设计系统思路
- 当前风格：偏 Notion 的温和留白、细边框、内容优先布局

## 当前内容

- `index.html`：单页首页，适合作为个人博客入口页
- 展示模块：Hero、最新文章占位、精选项目、近况、关于站点

## 后续可扩展

- 增加文章详情页
- 增加归档页与标签页
- 接入真实博客文章链接
- 增加 RSS / newsletter / 友情链接

## 本地预览

```bash
python3 -m http.server 8000
```

然后访问：`http://localhost:8000`
